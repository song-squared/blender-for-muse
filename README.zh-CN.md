# 🔩 blender-for-muse

[English](README.md) | [中文](README.zh-CN.md)

**Muse 有一台远端电脑，为什么不用它来做 3D 建模？**

一切从这里开始。✨

## 💡 为什么有这个项目

3D 建模有个看门人问题。😤
想要个零件？装 Blender、学界面、背快捷键、懂建模、懂布光、懂渲染——
几周教程下来才能做出第一个像样的模型。那些只是"想要个 3D 模型"的人，
大多倒在了第一步。

## 🚀 核心想法

开源项目 [mcp-for-blender](https://github.com/ahujasid/mcp-for-blender)
做了件很酷的事：让 AI 直接驱动 Blender。但它要你在本地装 Blender、
配 MCP 服务器——软件装在你自己的电脑上，环境自己接，服务自己维护。
所有麻烦都长在你的本地电脑上。😮‍💨

但 Muse 呢？每个 Muse 账号都自带一台远端电脑。有终端、有浏览器、
能装软件、能跑程序。💻

那还往本地装 Blender 干嘛？🤔

**一台 Muse 远端电脑，就是一整个 3D 工作室。** 🖥️

给 Muse 发条语音、发张截图。它在远端电脑上装好 Blender、
写好建模脚本、渲染出图、自己看图检查——你只需要拿走两样东西：

- 🖼️ 渲染图——从任意角度检查模型
- 📦 `.blend` 文件——本地 Blender 打开继续编辑

过去需要"装 Blender + 几周教程"的事，现在只需要
**一个 Muse 账号，就够了。**
云端建模，手机上看，本地零安装。☁️

更妙的是：**📱手机上也能做 3D 建模。**
手机上给 Muse 发条语音——"给我画一个 M12 的螺帽"——
它在云端建模，你拿回渲染图检查。
一台口袋里的 3D 工作室，不用电脑。

这里的创新不是算法，而是**观念——一种全新的工作方式**。💡
一种全新的 Muse 玩法：把远端电脑当成无限延伸的工作台。

还有一层变化：**过去要专家才能干的事，现在小白也能干了**。🌱

传统路线要求你学会 Blender——每一步都是看门人，
把那些"只想要个 3D 模型"的人挡在门外。🚧

Muse 版把门槛砍到只剩一句话：跟 Muse 说话。
这不正是 Muse 被设计出来的样子吗？AI 属于每个人，
不管技术水平。我们的目标一致。🤝

## 🛠️ 它能干什么

告诉 Muse 你想要什么——语音、文字、截图都行——它在远端电脑上建模：

- "给我画一个螺帽" → 按 GB/T 6170 建出 M12 螺母，渲染成图
- "内径改大一点" → 改参数，重新渲染
- "没有内螺纹吗" → 生成 M12×1.75 真实螺旋内螺纹几何
- "切一半看剖面" → 剖视图
- "做个旋转动画" → 转盘动画 mp4

```
你说话 → Muse（远端电脑）→ Blender → 渲染图 + .blend
```

## ✏️ 建完之后：随便改

两种改法：

**1. 跟 Muse 说** 🗣️

像跟人说话一样：

> "内径改大一点"
> "给我一张螺纹的俯视特写"
> "换成老 DIN 934 的尺寸"

Muse 改参数化脚本，重新渲染，把新图发你。
只动你说的那一处，别的地方原样不动。

**2. 自己改 .blend** 🖱️

本地 Blender 打开（blender.org 免费下载）——
模型、材质、灯光、相机全在里面。

## 🖥️ 大渲染？租台 VPS

远端机（2 核、无 GPU）只够验证和小场景。要出成品质量：

1. 租一台 Ubuntu VPS（多核 CPU 版便宜，带 GPU 的更快）
2. 把 SSH 连接信息（host、用户名、密钥）通过安全流程交给 Muse
3. Muse 照搬同一套流程装好，把 `s.cycles.device` 改成 `'GPU'`、采样调高，就开渲

建模参数一行不用动——只改渲染配置。完整步骤见 `SKILL.md` 第 8 节。

## ⚠️ 局限性（实话实说）

- **CPU 渲染慢**：2 核机器上 800×600 一帧约 90~160 秒，36 帧转盘动画约 20 分钟。
  这套流程定位是**验证和小场景**，大渲染请上 GPU 机器。
- **螺纹牙形是简化版**：视觉够用，不是真正的 ISO 标准牙形（真牙形牙顶牙底有平顶/圆弧）。
- **单张截图复现 3D 有边界**：简单硬表面零件（杯子、桌椅、标准件）可以；
  复杂有机形态（人物、动物）别指望，这是全行业的现状。
- **Blender 是网格建模器**：FBX/OBJ/glTF/STL 导出没问题，做视觉效果一流；
  要参数化 STEP 实体（带特征树、能改尺寸）请走 CAD 内核路线（如 text-to-cad），不是这个项目。
